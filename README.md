# 線上腦海｜實分析筆記
這個網站主要是給學習數學的我自己使用。我習慣用 XMind 這個筆記軟體來整理觀念之間的關係，但有時在做題時(尤其是剛開始學習一門學科時)，常常看到題目但腦海中完全沒有浮現任何想法，因此我希望不管是在初期建構知識亦或複習時皆能從卡住的問題找到定義、看懂一個例題，再沿連結回到整體概念脈絡，漸漸釐清這門學科的全貌。
即使是他人使用時(如:同學與助教)也能直接用瀏覽器閱讀。

## 開啟與發布
解壓後直接開啟根目錄(Root Directory) index.html。上傳到 GitHub 時讓 AGENTS.md 和 index.html 在儲存庫最外層。
Settings → Pages → Deploy from a branch → main → /(root) → Save。
## 編輯
可以將專案資料夾開成 Obsidian vault，在 notes/ 編輯 .md；請 AI 依 AGENTS.md 同步更新對應 HTML 與首頁。兩種格式目前由編輯者或 AI 同步維護。XMind 圖可選用 PNG 放入 images/；如在 GitHub 上看不到空資料夾，上傳第一張圖片時即可建立。
