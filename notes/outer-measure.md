# 外測度
如果還不知道集合是否可測，能先估計它有多大嗎？
## 概念
外測度 μ* 定義在 X 的所有子集上，取值介於 0 與正無窮之間（含兩端）。它滿足空集取零、單調性與可數次可加性。在實線上，Lebesgue 外測度取所有可數開區間覆蓋的總長度下確界。
## 例題
單點 {0} 可用長度為 ε 的開區間覆蓋，對每個 ε > 0 都成立。因此它的 Lebesgue 外測度介於 0 與每個 ε 之間，只能等於 0。
