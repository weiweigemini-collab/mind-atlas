# 零測集
為什麼每個非空開區間裡都有有理數，但整個有理數集的 Lebesgue 測度卻是零？
## 概念
在實線上，若對每個 ε > 0，都能用可數個開區間覆蓋 E ⊆ ℝ，且這些區間的長度總和小於 ε，就稱 E 為 Lebesgue 零測集。這表示 E 的外測度為零；由 Carathéodory 判準，E 可測，因此它的 Lebesgue 測度也是零。
## 例題
有理數集 ℚ 在實線上稠密：每個非空開區間都至少含有一個有理數。這句話告訴我們在哪裡可以找到有理數，卻沒有給出覆蓋這些點所需的總長度。
因為 ℚ 可數，可以把所有有理數列成 q₁, q₂, q₃, …。任給 ε > 0，以第 n 個有理數為中心，取一個長度為 ε/2ⁿ⁺¹ 的開區間（n 從 1 開始）。每個有理數都被自己的區間蓋住。
這些長度加起來是 ε/4 + ε/8 + ε/16 + ⋯ = ε/2，小於 ε。於是 0 ≤ m*(ℚ) ≤ ε/2。由於 ε 可以任意小，m*(ℚ) = 0，故 m(ℚ) = 0。即使這些區間的聯集碰到每個非空開區間，它的測度仍至多是 ε/2。
